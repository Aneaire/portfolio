# Client reply

Hi! Thank you for sending the detailed brief. I understand the type of website you want to build and the features you have in mind.

The part I would like to plan most carefully is the post builder and CMS. Since each post may contain several photos or videos, individual captions, different orientations, dates, tags, likes and publishing controls, the admin experience needs to match the way you want to create and organize your archive.

I’m confident this can be built. Before development starts, I would first finalize the post structure, admin workflow and visual direction with you. That way, the system is designed around your preferences instead of forcing the concept into a standard blog layout.

Astro and React would be used to build the website itself. You would manage the content through a separate CMS/admin panel where you can create posts, upload media, add captions, organize entries and publish them.

Unlike Wix or WordPress, the website would not depend on a pre-made theme or plugin structure. The design, post layout and admin workflow would be created specifically for your archive. You would own the source code, hosting account, domain, database and CMS account.

For handover, another developer would need access to those accounts, the source code repository, database, deployment settings and project documentation. I can provide a handover document explaining how the project is structured, how to run it locally and how to deploy future changes. The project would not depend on me personally to continue operating.

Based on the current scope, my initial estimate is:

- Timeline: approximately 5–7 weeks
- Development fee: would 20k fit to your budget?
- Includes the custom website, CMS/admin panel, media uploads, search and filtering, likes, basic analytics setup, responsive layouts and deployment
- Includes two structured revision rounds during development
- Includes one week of post-launch support for bugs and small adjustments related to the delivered scope

The timeline may change slightly depending on how quickly we finalize the design, post builder and CMS workflow. Hosting, domain registration, media storage and third-party service fees would be separate and would remain under your ownership.
